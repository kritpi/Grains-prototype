Visual identity — v2

Grains, printed
not rendered.

Black and white for the structure — the way a photograph actually is before anyone colors it in. Vivid color is rationed to two jobs only: one accent for "do this," and a small key of process colors borrowed from how film boxes and edge-printing have always told stocks apart at a glance.

Reference points — Saul LeiterCartier-BressonVivian MaierJoe GreerWillem Verbeeck

Four rules before any pixel

01

Labs are read, films are felt

Lab pages are dense and structured — pricing, hours, process. Film Stock pages are sparse and image-led. The same layout system should not make both feel the same.

02

A scan is never a lab's fault

Sample photos never carry a lab's name. Nothing in this system — no caption slot, no metadata row — should make that link possible by accident.

03

Respect the frame

3:2, 1:1, 6:7 — a photo keeps the ratio it was shot in. No cropping to fit a tile.

04

Thai carries equal weight

Not a translated afterthought in small type under the English — its own line, same size, same confidence.

Color

4 core + process key

Everything structural — text, borders, chrome — stays strictly black and white. The one hero color is a signal: it means "act here" and nowhere else. A second, small set of vivid colors exists only to key the four chemical processes, the way a Kodak box or a strip of edge-printing always has.

Typography

2 roles

A high-contrast serif for anything that's a name or a headline. A clean, minimal sans for everything else — body copy, interface, metadata — like an exhibition tag in a gallery. No monospace or typewriter faces anywhere in the system.

Grid & negative space

12 col

Content sits on a 12-column editorial grid but rarely fills it — the empty columns are load-bearing. Component edges carry real weight now (a 2px border, a sharp 90° corner); page-level rhythm stays a plain hairline, so the contrast budget is spent on things you touch, not on every rule.

Text measureBody copy holds ~65 characters wide even when the column is wider — width is for layout, not for line length.
Zero radius, alwaysEvery corner is a sharp 90° — no softening, no bubbles. Every bordered component in this system shares the same flat edge.
Asymmetry is fineA gallery grid can run edge to edge; a detail page keeps a generous margin. Density should match what the content actually is.

Filter chips — process-coded

A chip's border always carries its process color, even unselected, so a shelf of filters reads like a shelf of film boxes. Selecting one fills it solid. Scanner-model chips (equipment, not chemistry) stay plain black and white on purpose.

Frame respect

Three ratios, one rule: whatever the camera shot, the grid displays. Kept strictly monochrome here — ratio is a structural fact, not a process, so it stays out of the color key.

Do / don't

Do

  • Set Thai and English lab names as equal-weight siblings
  • Key a chemical process by color everywhere it appears — chip, card, filter
  • Leave an unfilled field visible as an invitation to contribute
  • Keep B&W processing literally colorless — it's the joke that isn't a joke

Don't

  • Put a lab's name anywhere near a sample photo's caption
  • Crop a sample photo to force a square tile
  • Use the process colors for status, mood, or anything that isn't chemistry
  • Round any corner, ever — that's generic-SaaS territory

The whole build from a docs-only repository to a launched product, in four phases: a sequential foundation on main, three parallel feature tracks in git worktrees, an integration-and-launch pass, and post-launch hardening. Every step follows the three pillars in docs/00_BACKLOG.md; nothing there is re-litigated. Anything decided here by default rather than by you is tagged Proposed and is cheap to overturn until the ticket that depends on it merges.

The brief arrived truncated between "Data Access Layer (DAL): labs" and "Ticket 2", and it names Phases 1 and 2 only. Tickets 0 and 1 are reconstructed from 00_BACKLOG.md's build order items 1 and 2 (Ticket 2 = item 3). Phases 3 and 4 cover the rest of that build order — film stocks, badges, Sentry, the cleanup cron, launch — so every deliverable has a home. One build-order item the brief leaves unassigned, film stocks, is given to Track B (P15). The brief also names MapLibre GL JS, CARTO Positron tiles and nuqs, which the docs don't yet carry; Ticket 0 records them.

Invariants acknowledged

  1. Workspace safety. Every file lands in this repository; scaffolding goes through an in-repo temporary directory.
  2. SQL exists only in lib/queries/. Pages, Server Actions and Route Handlers call those functions; the health check obeys this on day one.
  3. Schema-enforced rules stay in the schema. photos has no lab_id; lab_pricing foreign-keys to (lab_id, process); only curated services/supplies are indexed. Ticket 1 turns each into a test.
  4. Singapore co-location. Vercel functions on sin1; transaction pooler (:6543, prepare: false) for the app, session pooler (:5432) for migrations.
  5. Photos never transit the app server · Google-only auth · no Redis, no staging, no Terraform.

Gotchas to expect

  • Supabase free tier pauses a project after 7 idle days. Un-pause grains-dev before debugging a failing health check.
  • Pooler on 6543 requires prepare: false; both poolers require SSL (ssl: 'require').
  • Next 16: Turbopack by default; middleware.ts deprecated for proxy.ts — moot under P18.
  • Instrument Serif has no Thai glyphs. System fallback (Thonburi on Apple) until 3.3.
  • tsc needs next typegen first on a fresh Next 16 tree (P8).
  • Worktrees don't carry gitignored files. Copy .env.local into each one.
  • Signed upload URLs can't carry size or type limits. Bucket config does (P19).
  • Anything gated on the page actually rendering cannot be verified by headless automation. An IntersectionObserver never fires in a tab that is not compositing — nor does requestAnimationFrame — so a lazily-loaded section looks permanently stuck. The code is right and the harness cannot exercise it; verify by temporarily forcing the eager path. Found on A5's edit log, and the same shape as A4's isStyleLoaded() trap.
  • Appending a fetched page to React state is not idempotent. React mounts effects twice in development, so a fetch-on-mount renders the list twice. De-duplicate by id — which also covers a retry after a partly-successful load. Invisible in production, which is what makes it easy to ship.
